# SHADOW Android

Native Android client scaffold using Kotlin and Jetpack Compose.

## Build
From this directory, run:

```bash
gradle :app:assembleDebug
```

The debug APK is created at `app/build/outputs/apk/debug/app-debug.apk`.

This is the first UI scaffold only. Chat, microphone permissions, backend connection, memory and device actions are intentionally not advertised as implemented yet.
